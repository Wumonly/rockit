# Product Lens 命令

在动手写代码之前，先对产品决策进行诊断和压力测试。

## 执行

调用 `product-lens` skill：

```
/skill product-lens
```

## 适用模式

| 模式 | 用途 |
|------|------|
| 产品诊断 | YC Office Hours 风格 — 7 个尖锐问题验证"为什么做" |
| 创始人视角 | 审视项目方向 — 产品-市场匹配打分、10x 杠杆点 |
| 用户旅程审计 | 从头体验产品 — 记录摩擦点、评估 time-to-value |
| 功能优先级 | ICE 排序 — 影响力 x 信心 / 投入 |

## 输出

`PRODUCT-BRIEF.md` — 包含诊断结论、风险评估和 go/no-go 建议。

## 下一步

如果结论是 go，转交 `product-capability` 转化为可落地的能力计划。
