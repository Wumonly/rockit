# RocKit Research Playbook

Use this when the task is documentation-heavy, source-sensitive, or requires broad context.

## Defaults

- Prefer primary documentation and direct source links.
- Include concrete dates when facts may change over time.
- Keep a short evidence trail for each recommendation or conclusion.

## Suggested Flow

1. Inspect local code and docs first.
2. Search web only for unstable or external facts.
3. Summarize findings with file paths, commands, or links.

## Repo Signals

- Primary language: TypeScript/JavaScript, Python
- Framework: React, Vue, Next.js, NestJS, FastAPI
- Runtime: Node.js
- Package manager: npm
